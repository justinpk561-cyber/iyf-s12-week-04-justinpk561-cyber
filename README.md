## Project Description

This project focuses on learning JavaScript fundamentals and programming logic. It contains practical exercises covering variables, data types, operators, functions, loops, arrays, objects, and JSON.

It also includes a Student Grade Tracker mini-project and five daily coding challenges to strengthen problem-solving skills.

## Technologies Used

- HTML5
- JavaScript (ES6+)
- Git
- GitHub
- Browser Developer Tools

## Features

- JavaScript variables and data types.
- Arithmetic, comparison, and logical operators.
- Functions, arrow functions, and default parameters.
- Conditional statements and loops.
- Array methods and object manipulation.
- JSON parsing and stringification.
- Calculator mini-project.
- Student Grade Tracker.
- Five coding challenges:
  - FizzBuzz
  - Reverse a string
  - Find the largest number
  - Remove duplicates from an array
  - Check for palindromes

## How to Run

1. Clone this repository:
   git clone https://github.com/justinpk561-cyber/iyf-s12-week-04-justinpk561-cyber.git
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.
4. Open Developer Tools (F12) and select the Console tab to view the JavaScript results.

Alternatively, use the Live Server extension in VS Code.

- Navigating the correct repository folder when using Git.

These challenges were addressed through practice, debugging, and testing each exercise.
